## ⚙️ مستويات المزج الموصى بها

| النوع | Gain |
|---|---|
| الصوت (الراوي) | `1.00` |
| مؤثر بارز (صفارة، ستينغر، باب) | `0.30 – 0.42` |
| مؤثر متوسط (خطوات، ورق، كاميرا) | `0.20 – 0.28` |
| خلفية جوية (درون، حشد، شتا، ريح) | `0.09 – 0.26` |
| لاسلكي / كيبورد تحت الكلام | `0.11 – 0.16` |

**Ducking:** `depth=0.45` — الخلفية كتنخفض 45% ملي كيهضر الراوي.
