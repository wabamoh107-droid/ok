📄 التفاصيل: [`VOICES.md`](./VOICES.md) · 🔊 العينة: `samples/MY_VOICE.mp3`

## 🔄 كيفاش تصاوب حلقة جديدة

**1. السكريبت** — صفط النص الخام وقول: *"عاود كتبو كسكريبت تعليق صوتي"*

**2. التقطيع** — النص كيتقسم على مقاطع ~1150 حرف

**3. التوليد** — كل مقطع كيتولّد بـ `MY_VOICE` فـ `build/vo/`

**4. المزج** — `sfx/build_episode.py` كيلصق المقاطع ويحط المؤثرات

```bash
.venv/bin/python sfx/build_episode.py
```

## ⚙️ الإعداد

```bash
python3 -m venv .venv
.venv/bin/pip install numpy imageio-ffmpeg
cd sfx && ../.venv/bin/python make_sfx.py   # توليد المؤثرات
```
