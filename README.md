## 🔄 صناعة حلقة جديدة

**1. السكريبت**
صفط النص الخام وقول: *"عاود كتبو كسكريبت تعليق صوتي"*
→ هوك 30 ثانية · انتقالات سينمائية · تخفيف المحتوى الصادم · فقرات قصيرة

**2. الصوت**
النص كيتقسم على مقاطع ~1150 حرف، كل واحد كيتولّد بـ `MY_VOICE`

**3. المؤثرات**
```bash
.venv/bin/python sfx/build_episode.py
```
→ 60+ إشارة مؤثرات · ducking 47% · درون + ريح + شتا

**4. الصور**
~20 صورة مشاهد، ستايل موحّد: teal & amber · film grain · 16:9

**5. الفيديو**
```bash
.venv/bin/python video/build_video.py
.venv/bin/python video/make_thumbnails.py
```
→ لقطة كل 10 ثواني · حركة Ken Burns · 6 درجات لون · dip-to-black

## ✅ ضمانات

- 🎵 **بلا حقوق** — كل المؤثرات مولّدة رقمياً، بلا Content ID
- 🛡️ **بلا محتوى صادم** — بلا وصف دموي، مناسب للإعلانات
- 🖼️ **بلا صور حقيقية** للضحايا — كلشي مولّد
- 📅 **دقة المعلومات** — الأسماء والتواريخ كما هي فالمصدر

> `build/` و`.venv/` و`output/*.mp4` مستثنيين من Git.
